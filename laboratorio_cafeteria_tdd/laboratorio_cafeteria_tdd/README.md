# Laboratório — Café & Código

Arquivos: produtos.json (50 itens), index.html, style.css e app.js.

## Regras de negócio sugeridas
- Buscar por nome ou descrição.
- Filtrar por categoria.
- Adicionar produtos ao carrinho.
- Consolidar itens iguais e controlar quantidade.
- Subtotal = soma de preço × quantidade.
- Taxa de serviço = 5% do subtotal, limitada a R$ 10,00.
- Total = subtotal + taxa.
- Persistir carrinho em localStorage.
- Finalizar pedido com id, data/hora, itens, subtotal, taxa, total e forma de pagamento.
- Salvar pedidos no localStorage e limpar o carrinho após confirmação.
- Pagamento é somente simulação acadêmica; não solicitar dados bancários reais.
